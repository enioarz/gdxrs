## Seven-part source review

1. **Pins and isolation.** Rebuilt clean pinned GDX `9e2a8c8` with bundled zlib `da607da`, Release/static and system-zlib discovery disabled. Inspected link command and dynamic dependencies; no dynamic GDX/system zlib dependency. Full GDX/Zlib notices compare byte-for-byte with pinned sources. Official Rust 1.99.1 archives were checksum-verified against the dated distribution manifest. Cargo has no third-party dependency or native build script.
2. **Independent fixtures.** Inspected `fixture_cases.py`, recipe execution, expectation-before-generation ordering and all three transformation families. Expectations derive from authored inputs, not a Rust decoder. Regeneration compared complete semantics, byte properties and bytes except the disclosed audit string. Tampering and empty/missing coverage controls actually ran. The checksum-damaged upstream acceptance remains explicitly distinct from the required Rust rejection.
3. **Format.** Read F01–F21 and checked pinned implementation paths for byte-order primitives, 80-byte index reservation/pointer ordering, symbol serialization, raw `-1` count, 255/65535 width boundaries, prior-key/delta state, tags, defaults and acronym projection. Verified uniform-endian transformed inputs, stored/zlib blocks, a crossing record, optional domains and label case distinctions. Fresh specification checks verified all 21 source/fixture bindings. Hardening rules are distinguished from permissive upstream behavior.
4. **API coverage.** Reviewed the 92 function dispositions and six property accessors against the pinned YAML. Planned native, adapter and external-conversion work has explicit milestones and verification requirements. Legacy state/callbacks and external conversion are not silently added to the core. No implemented parity is claimed.
5. **Reader/resources.** Reviewed shared source identity and quota, positioned reads, lending buffers, lazy metadata, bounded alias walks, typed values and exact stored labels. Projection consumes framing; limits count public rows; errors terminate without exposing partial batches. Path conversion, capacities, simultaneous decoders and codec scratch are accounted for in the design. All 25 acceptance scenarios remain specified, not executed. The 128 KiB codec ceiling requires measurement in the codec task.
6. **Benchmark.** Reviewed native generator/sink and separate Python ordered digest recipe, all five returned variable fields, metadata verification, timing boundaries, CPU/RSS and warm-cache disclosure. The fresh small profile executed four scenarios, one warmup and five measured read/write repetitions each: 24 writes and 44 complete validating scans. No full-record collection in the timed driver, Rust speedup, cold-cache or large-profile claim.
7. **M1 prerequisites.** No unresolved layout/value/resource decision prevents the supported uniform-endian v7 reader work. Dependency/codec measurement, runtime reader acceptance, larger-than-RAM tests and later writer/index/parallel work retain their separate gates. Drafting M1 tickets after this acceptance does not implement them.
