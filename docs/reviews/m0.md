2. Check that fixture expectations predate native decoding, semantic streams compare in full, and tampering tests fail for the intended reasons. Inspect the byte-order/case/domain transforms rather than treating filenames as evidence.
3. Verify byte-layout/tag/default rules against immutable source and actual fixture bytes, especially the 80-byte index reservation, count sentinels, key-width thresholds and block crossings. Review intentional malformed-input hardening separately from upstream permissiveness.
4. Check all 92 function dispositions and six property accessors, including external conversion and legacy call-state adapters.
5. Inspect borrowing, metadata laziness, alias bounds, projection framing, codec accounting preconditions and terminal error behavior. The proposed codec ceiling is not a measurement.
6. Review native benchmark input recipes, independent ordered-result validation, timing boundaries, all five repetitions and raw trials. There is no Rust speed claim and no large-profile execution claim.
7. Confirm no unresolved M1 prerequisites in the supported uniform-endian v7 profile; identify any required fixes before authorizing M1 task specifications.
