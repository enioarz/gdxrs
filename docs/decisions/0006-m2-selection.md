# 0006 — M2 selection contracts and staged delivery

M1 is merged in `5cc766d`. Work proceeds on `m2-bounded-slicing`, beginning with task 012; tasks 013–016 remain pending. The M2 exit gate still requires spill-backed large metadata/request operations and independently oversized inputs under an enforced OS memory cap. Completing ID slicing alone does not release M2.

`Reader::selection(symbol, &[DimensionSelection])` validates and owns an immutable, source/requested-symbol-bound selection. A dimension has one clause: All, One, AnyOf IDs, an inclusive raw-ID Range, or a union of inclusive Ranges. Clauses are conjoined; members/ranges within one clause are unioned. Duplicate dimension clauses and reversed ranges are errors (`InvalidSelection`); out-of-source positive IDs are `InvalidReference`. Scalar symbols admit no dimension clauses. Exact IDs are one-based registration IDs, not lexical label order. Future label resolution produces these same identities without changing matching policy.

Selections own only fixed twenty-dimension state and fallibly allocated, root-budgeted copies of requested sets/ranges. ID sets are sorted/deduplicated; ranges are sorted/coalesced with charged original capacity retained. Sorting is in-place and allocates no hidden run buffer. Empty sets/range unions become explicit empty constraints without payload allocation. Validate all clauses even if an earlier clause is empty. Cloning a Selection shares its accounted state; source and selection buffers remain alive until the last owner drops. An oversized request returns BudgetTooSmall in task 012; spill-backed large request handling is a subsequent task, not an unbounded fallback.

`Reader::scan_selected(symbol, selection, options)` adds filtering while preserving M1 `scan` and ScanOptions. Decode and validate full rows, test all constrained dimensions, then append projected columns and decrement the accepted/public-row limit. Projection cannot remove keys needed for filtering or skip encoded fields. Empty selections and zero limits do no record I/O or decoder/output allocation after normal reference/options validation. Filters are evaluated without an index or leading-prefix prescan. Initial scans decode the necessary prefix or complete symbol; no reduced-I/O claim is inferred from fewer returned rows.

`ScanCursor::statistics()` distinguishes fully decoded public rows from successfully returned rows. Decoded includes rejected and failed-fill rows that decoded completely; returned counts only complete batches exposed to the caller. Synthetic universe/scalar rows count as public rows, without implying physical records/bytes. Source IoStatistics remains a shared physical-read counter. After error, the cursor stays terminal and publishes no partial batch; prior rows remain partial results. Selection/source mismatch must fail before data I/O.

Fixed standard Arc controls retain M1's explicit allocator-OOM behavior, with precharged fixed allowance; all variable payloads remain fallible. No dependency, lock, index, worker or native runtime is added. Filters do not silently renumber keys or introduce label strings into record output. Future paging/spill/storage limits get their own concrete contracts before implementation.
