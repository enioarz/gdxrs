## Revisions and behavior

Base: merged #13, `926cfff`. Implementation:
`21d5a2e503fc7ff84dfa9fcfc7964eb0a22197b8`; final code:
`ff3840b9f99929b9684ba2ec2f24a787afc0ec08` (Windows builder declaration fix).
The [contract](../decisions/0014-writer-metadata.md) preceded implementation;
its refinements document fallible producers and retained cleanup ownership.
[Structured results](020-results.json) bind checks to the final code revision.

`begin_metadata(&MetadataOptions)` starts optional registration; the options reuse
the proven SpillOptions configuration. `register_uel` preserves accepted exact
bytes/case and returns its first dense ID. `register_uels_fresh` consumes a fallible
iterator of borrowed bytes or fixed owned arrays, externally sorts label/ordinal
pairs, resolves a checksummed fixed disk ordinal index, assigns dense IDs in
original first-occurrence order and streams every ordinal-to-ID mapping through a
fallible callback. No unique-input promise or lexical remap is accepted. Producer
errors precede callbacks; callback errors are terminal and cannot replay.

Writer-bound symbol IDs reject foreign writers. Symbol/acronym names share a
folded ASCII namespace; labels preserve native-compatible <=63-byte printable,
quotable bytes, including empty/high-byte/space labels. Descriptions/comments/text
are checked <=255-byte NUL-free strings. No truncation or UTF-8 normalization.
`register_symbol`, `add_comment`, `add_set_text`, `add_acronym` and `set_domains`
spool all metadata incrementally. Freeze validates counts, forward names,
strict-domain/alias target type, arity and alias cycles. Alias chains serialize
the resolved underlying set ID. Strict and relaxed domain modes are explicit;
mutation after freeze fails. Finish can freeze automatically.

The concrete publication gate emits minimal zero-record data headers, complete
metadata and empty symbols. Empty scalars retain native default-row semantics.
This does not implement arbitrary nonempty records or the task-021 sorted writer.
No new dependency, unsafe code or native production link was added.

## Storage, limits and failure ownership

Checksummed, offset-bound <=1024-byte frames retain lengths, IDs and original
ordinals. Reads check framing, checksum and exact tracked file extent. One journal
and up to two bulk auxiliaries each use a fallible fixed 32 KiB buffer. Controls
and bounded paths share the writer/Reader root. The sorter now accepts explicit
budget ownership with optional reader provenance; existing reader membership
validation and error source IDs remain intact. No dummy Reader is created.

Metadata/auxiliaries receive half the configured aggregate scratch-byte cap;
one sorter receives the other half, including coexistence during merging. Three
scratch handles are reserved for metadata; remaining handles bound the reduced
merge fan-in plus output. Six total are required. Peak statistics conservatively
sum share peaks. Output GDX extent/handle and caller-owned producer/consumer
retention are separate; these counters are not physical disk/RSS limits.

Failure/cancellation closes handles and attempts all owned cleanup, preserving
primary/secondary errors. If spill cleanup outlives a failed merge, Writer retains
its created directory and can retry streamed validated numeric-run cleanup through
abort. Unexpected entries/symlinks are preserved. A post-publication metadata
cleanup error reports Failed/published and preserves the valid destination. Drop
cleans without publishing. Private namespaces must remain trusted and stable.

## Limits and next task

Incremental duplicate and symbol/reference scans are bounded disk scans and may
be quadratic. Use the bulk fresh-dictionary path for large UEL dictionaries.
No writer throughput parity, general string/mapped/unsorted record output,
OS-capped RSS or whole-M3 completion is claimed. Task 021 adds borrowing sorted
nonempty record output; full writer interoperability and scale remain 022–023.
