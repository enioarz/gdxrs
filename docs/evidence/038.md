## Order, bounded admission and lifecycle

The fixed shared-root slots own at most one task and one reusable batch per admitted
worker. Initial decoder/checkpoint/batch storage and rounded explicit stacks plus
64 KiB guards and 256 KiB thread/control allowances are reserved before spawning.
Later tasks prepare before dispatch after retiring old state. There is no partition
result collection or growing reorder map. Requested/admitted workers, reservation
bytes, slot peaks, speculative work and joins are observable. Exact admission rejects
budget-driven reduction; explicit Reduce retries only BudgetTooSmall before spawn.
Zero limits, empty selections and verified empty symbols launch no threads or
record work. Validated-index recovery avoids repeated full hashing/replay.

Frozen native order/value checks cover all symbol kinds and codecs. Focused tests
exercise selection/projection/global accepted limits, truncated exposed column
lengths, slow first partitions, blocked producers/coordinator/task waiters, rejected
row polling, external cancellation, consumer drop, spawn/read/decode failures,
worker/join panic, poisoned state, source changes and post-output sidecar failures.
Every started worker joins. Errors remain sticky with acknowledged progress; no
later partition escapes or serial replay occurs. Partial-spawn failure retains
its original IO error, original cleanup denial and additional join diagnostic.
A retained cancellation handle keeps only the small charged signal after bulk
state is dropped. A controlled blocked source read proves cancellation retains
worker ownership until that read returns; no wall-clock interruption is promised.

Self-review found and fixed a missed-wakeup race between stop publication and wait
registration. Signal-gate ordering and a deterministic regression close that gap.
It also found that source mutation during final joins could escape completion;
both full exhaustion and accepted-limit completion now recheck after joining,
with tests preserving the exact acknowledged prefix. The initial smoke helper
failed because it expected a nonexistent native `head` response field. Its retained
failed report and correction to an independent Python prefix recipe are recorded;
all final cases pass unchanged containment/digest guards. Late cancellation requests
can no longer retroactively invalidate a completed scan; zero/empty and limit/reuse
regressions check terminal statistics remain stable.

## Measured resource scope and limits

Both parallel profiles enforce a 256 MiB library root and 512 MiB soft/hard Linux
address-space limit in noncollecting child processes. The million-row matrix peaks
at 14,699,492 root bytes, 419,282,944 VmPeak bytes, 11,841,536 measured RSS bytes and
five sampled file descriptors. Smoke peaks are 11,160,932 / 415,461,376 / 11,829,248
bytes respectively. Raw/zlib million-row source sizes are 46,144,222 / 10,575,882
bytes; neither source is independently oversized. Full results match native digests;
head/cancelled prefixes match independent Python recipes, and zero reads do no
record/codec work. Source and sidecar identities are retained before owned cleanup.

These are functional two/four-worker diagnostics, not eight-worker containment,
other-platform OS memory qualification, general speedup or independently oversized
parallel acceptance. Library accounting does not model universal allocator-arena,
VM or RSS behavior. Fixed small standard Arc/thread control allocations retain
Rust's allocator-abort limitation; variable storage and OS spawning are fallible.
Same-Reader concurrent allocations can cause later task preparation to fail within
the root. Active work counters are completed-step snapshots; joined counters include
speculation/rejections, and observed speculative errors remain fatal beyond a prefix.
Reader aggregate IO avoids double-counting overlapping worker measurements.
Synchronous OS reads are not forcibly interruptible, and existing source length/mtime
immutability assumptions remain. Task 039 is next after review; task 040 still gates
performance and independently oversized acceptance. No independent review is claimed.
