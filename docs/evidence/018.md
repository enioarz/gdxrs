## Public behavior and resources

`Writer::create` owns a standalone root budget; `Reader::create_writer` shares
its reader's root without retaining the source handle. `WriteOptions`,
`WriteStatistics` and `WriteStatus` expose limits and terminal/publication state.
`finish` emits a valid little-endian, uncompressed v7 file. `abort` cancels and
permits owned-temporary cleanup retries; Drop cleans up without publishing.

The fixed, fallibly allocated output buffer is 32 KiB. Path/control allocations
are conservatively charged before filesystem mutation, paths have explicit
length bounds, and a one-MiB root succeeds. Shared-root exhaustion and allocation
failure are tested before creating files; the final owner releases all charges.
No runtime dependency was added. Library accounting is not an RSS guarantee.

Output is exactly 197 bytes. Physical writes total 249 bytes because the
52-byte major index is overwritten; an exact 197-byte logical-output cap passes.
Independent byte expectations check the bootstrap, producer/system strings,
reserved bytes and six section offsets `[126, 163, 144, 179, 126, 0]`.
All three Rust feature configurations produce SHA-256
`cb0df5e7d6aa7e82798a32a9731aaf0aa559b26172a7c45dd0e49e2edfb0f4f1`.

An exclusive same-directory temporary is flushed, index-patched, flushed,
synced and closed before exclusive hard-link publication. Existing files,
directories, dangling Unix symlinks, late destination collisions and foreign
temporary-name collisions survive unchanged. The destination is never replaced.
A failure after publication records `Failed` with `published: true`, preserves
the valid destination and allows temporary cleanup retry.

Eight focused unit tests and one public integration test cover short/interrupted
and zero writes, create/write/seek/sync/publication/removal failures, partial-write
statistics, exact quota boundaries, shared-root admission/release, allocation
failure, Unicode paths, cancellation, idempotent completion, terminal errors,
primary plus secondary cleanup errors and publication timing. Failure injection
uses safe thread-local test hooks. Unix temporary permissions are checked as 0600.

## Review, limitations and next gate

Author review checked quota admission, temporary ownership, short writes,
terminal states, publication ordering and primary/cleanup error preservation;
the focused tests above exercise those paths. No independent review is claimed.
The standard library cannot report `File` Drop/close errors; explicit `sync_all`
is checked. Directory sync, power-loss recovery and durable directory publication
are outside this contract. The existing parent directory and namespace must be
trusted and stable. Publication requires same-filesystem hard-link support.
Windows inherits directory ACLs; its symlink-creation privilege is not required
by these tests. Logical output quotas do not bound filesystem allocation blocks.

No symbol/UEL registration, record output, Rust compressed output, writer scale,
RSS or throughput qualification is claimed. Native empty output with compression
flag 1 does not establish compressed record-writing coverage. Task 019 adds the
bounded stored/zlib encoder; metadata spooling, sorted records, complete
interoperability and the OS-capped M3 acceptance follow in tasks 020–023.
