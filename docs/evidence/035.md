# Task 035 — Persistent slice acceptance (in progress)

Branch `m5-acceptance`, based on task 034 merge `d34176d`.
[Decision 0030](../decisions/0030-m5-acceptance.md) specifies ordered-bound planning,
resource/cold-cache contracts and fail-closed acceptance thresholds.

A small diagnostic probe reproduced ~1.29 s / 327,680 index-page reads for a warm
65,536-interval leading slice versus ~0.016 s serial. Ordered leading-bound searches
and a bounded sequential window reduce the same output to ~1.5 ms / 200 page reads
and 2,048 decoded rows. These are preliminary, cache-reused probe measurements,
not larger-than-RAM qualification or general latency parity.

Capped smoke covers growing records, dictionaries and directories, three build/
reopen/cold trials each, complete native/serial/indexed identities and warm reuse.
Full source-bound scale, regression and four-platform gates are pending. No M5
release or independent approval is claimed.
