## Review findings and remaining scope

- Raw end and accepted limit must be independent; selected all-rejected windows
  prove the cursor cannot decode outside the range to fill a limit.
- EOF ordinal alone does not prove framing. Retain a no-output EOF iteration,
  distinguish explicit limits/empty ranges, and preserve sticky errors/progress.
- Cap batch allocation by possible raw rows; otherwise a tiny range can deny a
  sufficient shared root. Keep one iteration for EOF even when no raw rows remain.
- Empty aliased construction can resolve catalog metadata. Lazy consumption does
  no record/codec work; tests distinguish these instead of claiming zero metadata I/O.
- Retain source ownership and copied restart state; authenticated sidecar trust is
  established before capture, not repeated independently for every range.

Full M3/M4/M5 scale gates were not rerun for this serial primitive; their preserved
source-bound reports are historical. Task 040 gates new worker/oversized containment
and performance. Existing source length/mtime assumptions remain, with no CAS or
indistinguishable-edit guarantee. Native platform functionality is separate from
Linux containment/timings. Task 038 remains pending until this task's review.
