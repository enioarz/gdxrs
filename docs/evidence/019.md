## Code and contract

Code revision: `6f4bce8ba6295563af5fe33fbefa276fda32a05e`, based on merged
#12 (`3fa50b75c53f8d3e7752e802e8ff457161db8bc7`). The
[allocation/API decision](../decisions/0013-bounded-writer-codec.md) was committed
before code. [Machine-readable evidence](019-results.json) binds the local reports,
source pins, hashes, resource bounds and workflow state to the code revision.

`WriteOptions::compression` selects `WriteCompression::{None, Zlib}`; None remains
the default. Little-endian output only. The private reusable section encoder
accepts borrowed bytes, little-endian scalars and checked u8-length strings.
Independent decoded blocks are at most 32768 bytes. Level-1 zlib output is used
only if strictly shorter than the raw block; otherwise write stored framing.
Every block has a fresh dictionary/checksum. Empty flushes emit nothing; a partial
final block flushes once. Sink/encoding failures are terminal and cannot replay.
The entire framed block is passed to output admission together. Each metadata
section ends before recording the next physical offset, and only the raw index
is backpatched. The existing no-clobber transaction/abort/cleanup contract stays
in effect. Symbol/UEL registration and record output remain absent.

## Allocation and dependency audit

The existing pinned miniz_oxide encoder requires `with-alloc`; the inflater does
not. Enable exactly that feature with `compression`, retaining the same versions,
checksums, licenses and two-dependency graph. The dependency gate now requires the
audited feature and still rejects version changes, missing/unexpected features,
SIMD and extra dependencies. Minimal builds retain zero runtime dependencies and
reject requested Zlib before creating files or reserving encoder state.

A compressed section encoder reserves 458931 bytes on the tested native target:
32768 input + 32771 complete framed output + 65712 visible codec state + 327680
conservative private-heap allowance. The visible state and data buffers use
fallible exact allocations. The five private fixed boxes total 253614 payload
bytes on native targets, covered before construction by that allowance. They
retain the safe standard-owner allocator-OOM abort exception documented in
decision 0003. No file/input count controls their size; no compressor convenience
Vec API, clone, growing output, native codec or unsafe code is used. Raw mode adds
no encoder allocation. These are tracked library bounds, not RSS measurements.
