## Delivered

`Reader::selection` compiles source/requested-symbol-bound immutable selections: All, One, AnyOf, inclusive Range and union of Ranges. Distinct zero-based dimension clauses are conjoined; members within a clause are unioned. Invalid dimensions/duplicate clauses/reversed ranges return InvalidSelection; out-of-file IDs return InvalidReference. Validation covers every clause before copying any variable payload, including clauses after an explicit empty set. ID sets and ranges normalize in place with original capacities charged to the shared root quota. Clones retain the same allocation and source.

`Reader::scan_selected` tests complete decoded keys before projection and exact accepted-row limits, preserving original IDs, order, typed values and terminal errors. Explicit empty selections and zero limits read no data and allocate no decoder/output. Existing M1 scan/ScanOptions remain compatible. Cursor statistics distinguish fully decoded public rows from rows actually exposed in successful batches; failed fills never increase returned_rows. This is index-free slicing; fewer returned rows do not imply fewer bytes decoded.

## Resource and failure evidence

Selection fixed state reserves 16 KiB before shared-owner construction and is size-checked against that ceiling. AnyOf copies reserve input capacity × actual UelId size; range unions reserve capacity × actual UelRange size. Exact fallible buffers retain charged capacity after in-place normalization. An oversized 300,000-ID caller request under a 1 MiB root budget is rejected, without a full-table allocation or leak. Duplicate IDs are not permission to exceed the cap before normalization. Clone/cursor retention is tested, and final-owner drop releases the entire root requested-byte count to **0**.

A scripted seven-byte source proves selected-empty scans perform zero positioned reads and add no decoder/output storage. Invalid projected options are still rejected for empty selections. Runtime tests also use corrupt record data to show empty/zero-limit scans never decode it, while nonempty scans expose its typed terminal error. In the filtered fault case, peak library logical requested memory is **208,063 bytes**; buffered matching rows in the failing fill never escape, decoder/output quota is released, and previously returned rows stay counted as partial output. This is **not RSS or an OS-capped scale result**.

Fixed standard Arc control allocations retain M1's documented allocator-OOM abort limitation. No unsafe code, hidden dictionary, index, spill, global decoder lock or native runtime is introduced.
