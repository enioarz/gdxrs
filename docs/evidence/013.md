## Delivered contracts

`lookup_labels` owns request bytes/ordered descriptors, resolves a nonempty small batch in one complete UEL-table pass, and exposes each original ordinal/label and optional file ID. Case and raw bytes remain exact. Duplicate requests remain distinct, unknowns are None, and repeated stored bytes choose the first ID. The byte/descriptor/temporary-index capacities jointly have a **128 KiB** ceiling, also charged to the root quota. In-place ordinal sorting adds no hidden heap buffer; fixed state has a 16 KiB reservation. Oversized requests return BudgetTooSmall until task 015 provides spill; lengths above 255 are InvalidOptions.

`selection_from_labels` validates source/symbol/dimension, then composes the known ID union with task 012 filtering. Its temporary and owned ID copies are both accounted. Unknown/empty results become explicit empty selections and perform no record reads when scanned.

`uel_labels` lends ID-to-label bytes with at most two cursor-local 128-label LRU pages. Page payloads, complete control headers and checkpoints count against a source-wide metadata-cache quota shared across Reader clones/cursors, while root accounting charges actual buffers/fixed state. Misses resume a retained predecessor checkpoint or scan a prefix; no UEL-sized directory/map is built. Zero/tiny/full cache allowances fall back to bounded scans. Stream/codec scratch is root-charged and dropped before returning a view; no encoded block is retained as extra cache storage. Cache hits avoid positioned reads but still check file immutability. Errors clear pages, retain context and become terminal. Symbol lookup keeps its existing bounded cold-catalog scan.

The concrete API, ownership, cache admission/eviction and error rules were recorded **before implementation** in [decision 0007](../decisions/0007-label-lookup-pages.md).

## Accounting and author review

Measured layouts on the tested toolchain: cached page charge **32,848 bytes** (32,768 payload plus complete optional header), `UelLabelCursor` **592 bytes**, `LabelMatches` **120 bytes**. Cursor/result fixed allowances are conservatively reserved at 16 KiB, separately from payloads. The positioned-read/final-owner probe peaks at **141,663 logical root-requested bytes** and returns to **0** after all source-owning objects drop. Cache/global/root charges and exact-capacity arrays are distinct; test spy input/log storage and consumer copies are outside library accounting. No RSS or OS-containment measurement is claimed.

Author review examined request/descriptor size arithmetic before allocation, initialized ordinal indices, one-based ID bounds, page endpoints within the signed format count, two-slot LRU ownership, complete string-table checkpoint state, source checks on hits, exact labels-to-selection composition and terminal cleanup. Fixed controls retain the explicit standard shared-owner allocator-OOM limitation; all variable buffers are fallible. There is no global decoder lock, per-file offset vector or hidden whole-table cache.

Initial test code guessed padded `u00001` labels; the authored fixture generator/expectations use `u1`, and tests were corrected to those existing inputs. The hit test now explicitly repeats the last label, including one-label tables. Neither fixtures nor acceptance assertions were weakened. The initial crossing probe covered stored blocks; review expanded it to both stored and zlib envelopes and reran the full gate. All findings are resolved. This is **author review**, not independent M2 release approval.
