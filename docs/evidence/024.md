## Implementation and contracts

`Writer::begin_unsorted_symbol` accepts arbitrary-order writer-owned raw UEL IDs
and typed values. Complete records fit fixed 145-byte packets in the existing
255-byte spill key, preserving original registration IDs without a second record
spool or spill-format change. Sorted merge streams through the existing encoder.
Duplicate raw keys fail even when their values differ. Scalars, domains, ordinary
numeric bits and tagged special/acronym values retain sorted-writer rules.

The run buffer, replay key buffer and controls share the existing root budget.
MetadataOptions' existing journal/sort scratch shares and bounded handles apply;
no cap is raised. Completion exposes per-job spill statistics. Abandonment and
ingestion/merge/replay failures prevent publication. Cursor handles close before
parent cleanup; metadata retains nested scratch ownership across consuming-sorter
failures for retryable abort, with secondary cleanup errors preserved.

Nine focused tests cover multiple merge passes, dimensions 0/1/2/20, all supported
kinds/subtypes, raw/zlib, exact numeric/special/acronym bits, duplicate/scalar
errors, foreign IDs, bounds, domains, malformed/corrupt runs, count and allocation
failures, root/scratch/output limits, merge read/write failures, abandonment and
cleanup retry. A public API test shares the Reader/Writer root, checks original
registration IDs, ordered results, spill statistics and released charges.
