## Behavior and ownership

`begin_deferred_records` stages contiguous symbol groups in any dependency or row
order using a single checksummed parent-owned Store. Registered raw, caller-mapped
and exact string keys retain identity and typed values. Metadata and labels must
be registered first. Dependency passes finalize strict-domain sets before their
dependents; untouched sets participate as empty groups. Direct set self-domains
match native behavior. Universe/relaxed domains do not restrict membership.
Unresolvable dependency cycles fail explicitly. Alias chains are validated while
direct referenced alias IDs and registration IDs remain intact.

Each ready group reuses bounded external sorting and disk-backed membership.
Original global and per-symbol ordinals survive; ordinal sort prefixes establish
first-valid-input duplicate winners. Membership errors take priority over duplicate
errors and include every bad axis. Existing APIs plus deferred `finish()` retain
terminal rejection. Explicit `finish_reporting` emits every rejected domain or
duplicate row through a borrowed fallible callback, under record and logical-byte
quotas. It preserves raw keys, values, ordinals, origin and mapped/string provenance.
No library error vector or in-memory domain/dependency graph is retained.

`scan_mapped_reporting` similarly reports missing-map rows and all missing axes,
including mappings that do exist, before applying Error/SkipRecord policy. Zero
limit reports nothing and positive limits remain after mapped ordering. The map
owner retains partial error statistics on failed prescans.

The spool consumes the existing journal-space half, one existing handle slot and
the shared root. At least seven total scratch handles are needed, or eight with a
retained caller map. Parent cleanup force-closes the spool before removal; failed
removal retains abort-retry ownership. Replay closes its cursor explicitly even
on failure and attaches secondary cleanup errors before parent cleanup. Symbol
initialization errors cancel the already-owned sorter first. If cursor and parent
cleanup both fail, the first cleanup diagnostic survives and parent retry ownership
remains retained. Terminal replay errors
are preserved after metadata cleanup rather than replaced with missing-state errors.
Every public deferred method checks terminal state first, so later adapter calls
and either finish mode preserve the original ingestion error and invoke no sink.
Callbacks/quota faults cannot publish. `reported` and `bytes` acknowledge only
successful callbacks; `errors` includes the next rejected row that cannot be
reported. Earlier callback side effects cannot be rolled back or replayed implicitly.
