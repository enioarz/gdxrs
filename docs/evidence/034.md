## Delivered contract

`Reader::scan_selected_indexed` consumes an explicitly obtained `IndexOpen`.
No query opens, validates, hashes or builds a sidecar implicitly. Off/Missing/
Rejected use exact serial selection before output, preserving rejection diagnostics.
Ready validates same open source and requested symbol/alias ownership. Consuming
or cancelling the cursor with `into_index` recovers its session for warm reuse.

Planning streams authenticated interval summaries without a candidate collection.
Conservative per-axis overlap only rejects proven misses; the unchanged residual
selection evaluates original IDs before projection and global accepted limits.
Adjacent candidate spans share the decoder; a gap releases it before admitting a
verified restart. All/disk-only predicates start sequentially. Poor pruning switches
to a sequential tail based on observed intervals, without an index/record prescan.
The final candidate retains its pending terminator unless an accepted limit stops
first. One span, one index cache and decoder/batch/selection controls share one root.

InvalidIndex before any acknowledged batch can discard and restore an unpublished
fill and start serially. Its tentative limit is rolled back; actual decoded work
remains counted. After output, failures are sticky and terminal, with acknowledged
progress preserved. Source/access/budget errors remain errors. Source integrity is
checked at fill entry, interval access and successful fill exit. Ordinary lending,
projection and cancellation behavior is retained.

Counters distinguish decoded/acknowledged rows, considered/pruned/coalesced
intervals, successful checkpoint restarts, query index reads/cache hits and source
I/O/decoded-buffer deltas. The immutable strict-open snapshot stays separate from
cumulative session query work across warm reuse. Explicit digest/replay times remain
reported by task 033; they are not hidden in a warm-query speedup.

## Self-review findings and limits

Before-output fallback must roll back unpublished rows and the tentative global
limit, while retaining actual decoded work. A two-island fault proves no duplicated
output or lost limit. Last-candidate EOF requires a final decoder call; a separately
corrupted terminator proves this remains enforced after acknowledged rows. Warm
statistics initially included prior queries' page work in validation; a retained
successful-open snapshot and regression now keep the phases distinct. Module path,
explicit raw-ID comparisons and Clippy issues were corrected without suppression.
All final gates were rerun at the named revision after these changes.

No new dependency, parallel execution, postings or GDX byte-format change is
introduced. Strict sidecar reopen still includes a full source hash and symbol
replay. Source integrity retains the immutable-reader length/mtime contract,
including its indistinguishable-edit/concurrent-writer limitations. Source I/O
counters cover cursor calls; simultaneous I/O on the same Reader source may
contribute, as with Reader::io_statistics.

Planning uses bounded authenticated point paths and a one-page cache, which can
require multiple directory reads per interval. No latency, throughput parity,
OS/RSS containment, larger-than-RAM query, cold/warm break-even or M5 release is
claimed here. Task 035 must measure growing oversized records/metadata/directories
under the specified 256/512 MiB caps and perform its >=3-trial acceptance checks.
